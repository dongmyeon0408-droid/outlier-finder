이 앱이 찾는 것 — 아웃라이어

유튜브에서 조회수는 보통 구독자 규모를 따라갑니다. 그런데 가끔 구독자 1천 명 채널의 영상이 50만 회가 나옵니다. 채널의 힘이 아니라 제목·썸네일·소재 자체의 힘으로 알고리즘이 밀어준 것 — 이것이 아웃라이어이고, 크리에이터에게 가장 확실한 벤치마킹 재료입니다. 이 앱은 그 영상만 걸러내는 도구입니다.

시작하기 (최초 1회)

  1. Google Cloud Console(console.cloud.google.com) → 새 프로젝트 → 「API 및 서비스 → 라이브러리」에서 YouTube Data API v3 사용 설정
  2. 「사용자 인증 정보 → API 키 만들기」 → AIza... 키 복사
  3. 이 앱 Step 1에 붙여넣고 저장 — 키는 이 브라우저에만 저장되며 외부 전송되지 않습니다. 저장 후 카드는 자동으로 접힙니다 (제목 클릭으로 다시 열기)

YouTube API는 하루 10,000유닛 무료이며 한국시간 오후 4~5시경 초기화됩니다. 상단 카운터가 오늘 사용량입니다.

추천 루틴 — 아침 5분

  1. 급상승 차트 → 불러오기 → 💎 소형채널 히트작만 → 🌱 영상 제목·썸네일 훑기 ~15유닛
  2. 눈에 띈 소재를 키워드 트렌드에서 채굴 → 3~5개 선택 → 📊 검색량 검증으로 수요 순위 확인 ~500유닛
  3. 1위 키워드로 💎 영상 발굴 → 터진 레퍼런스 수집 ~205유닛
  4. Step 4에서 제안 5개 생성 → 마음에 드는 것을 복사해 대본 작업 시작 0유닛

제작 딜레이가 걱정되면 Google 트렌드 12개월 버튼으로 우상향 추세인지 확인하세요 — 상승 중인 키워드는 게시 시점에 수요가 더 커져 있습니다.
